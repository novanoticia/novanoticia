# Hola, soy Pablo

Construyo skills y plugins para asistentes de IA (Claude, Codex, Perplexity, Le Chat) con una idea común: que la IA ayude a **pensar mejor**, no solo a escribir más rápido. Casi todos los proyectos incluyen razonamiento estructurado, alternativas explícitas, autocrítica y límites declarados: el criterio final es siempre humano.

Web: [mindandhealth.org](https://mindandhealth.org/)

## Pensamiento y juicio profesional

| Repositorio | Qué hace |
|---|---|
| [auditor-filosofico](https://github.com/novanoticia/auditor-filosofico) | Examina evidencia, conceptos, argumentos y supuestos con análisis epistémico y autocrítica. Multiplataforma. |
| [cie11-formulacion-clinica](https://github.com/novanoticia/cie11-formulacion-clinica) | Apoyo a la formulación clínica con CIE-11: diferenciales obligatorios, lagunas y riesgos. |
| [codigo-civil-formulacion-juridica](https://github.com/novanoticia/codigo-civil-formulacion-juridica) | Estructura casos civiles con el Código Civil español, sin emitir dictamen. |
| [seudonimizador-clinico-juridico](https://github.com/novanoticia/seudonimizador-clinico-juridico) | Seudonimiza casos clínicos y jurídicos conservando valor analítico (no es anonimización RGPD fuerte). |

## Automatización personal en Mac

- [pablo-things3](https://github.com/novanoticia/pablo-things3): crea tareas en Things 3 desde lenguaje natural.
- [claude-plugin-timemator](https://github.com/novanoticia/claude-plugin-timemator): controla Timemator desde Claude Code.

## Cómo encajan

`repo-auditor-ia` audita, `alternancia-modelos` orquesta, `claude-skills-exporter` distribuye, y el resto son las skills que se auditan, orquestan y exportan.
